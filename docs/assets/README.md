# Portfolio screenshot checklist

This directory is the safe, tracked home for **sanitized** recruiter-portfolio screenshots. The application’s real candidate data, CV, database, logs, and browser profile remain ignored elsewhere.

Capture the following from the read-only Streamlit **Demo** page at normal desktop width:

1. `pipeline-and-opportunity.png` — the discovery funnel and selected opportunity.
2. `requirement-evidence-mapping.png` — the requirement-to-evidence table.
3. `trust-and-human-review.png` — the trust, architecture, and human-review material.

Before committing an image, confirm that it contains no names, email addresses, phone numbers, document text, application answers, ATS session/browser chrome, local paths, access tokens, or other sensitive data. Do not use mock screenshots or alter product data solely for presentation.
